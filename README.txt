ОТКРЫТКА ДЛЯ ПОЛЕЧКИ ♡

Как открыть:
1. Распакуй ZIP в отдельную папку.
2. Открой index.html в браузере.
3. Нажми «тыкай, любимая», чтобы перейти на вторую страницу.

Файлы:
- index.html — главная страница
- postcard.html — длинная открытка, которую можно листать вниз
- style.css — весь дизайн
- script.js — анимации и кнопка сюрприза

Как менять текст:
Открой index.html или postcard.html в любом редакторе кода (например, VS Code) и меняй текст прямо внутри HTML.

Как добавить фотографии:
1. Положи файл фото в эту же папку.
2. В postcard.html найди нужный блок <div class="photo-placeholder ...">...</div>.
3. Замени его, например, на:
   <div class="photo-placeholder"><img src="photo1.jpg" alt="Наше фото" style="width:100%;height:100%;object-fit:cover;border-radius:14px"></div>
4. Повтори для остальных фотографий.

Примечание:
Шрифты загружаются из Google Fonts, если есть интернет. Без интернета сайт тоже откроется, используя запасные шрифты.
